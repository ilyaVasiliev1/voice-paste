# Архитектура VoicePaste — целевая

Что есть сейчас и где лежит — `docs/map.md`. Здесь — к чему приходим и почему.
Решения, которые трудно откатить, — `docs/decisions.md`. Замеры и исследование —
`research/2026-10-14-*.md`. Что не проверено — последний раздел.

## Качества (по важности для владельца)

| № | Качество | Сценарий | Мера |
|---|---|---|---|
| Q1 | Чистый текст | Диктую 30 с по-русски с английскими терминами | знаки и заглавные на месте; нет «Thank you» и «Продолжение следует»; тишина даёт пустой результат, а не фразу |
| Q2 | Скорость | Отпустил клавишу | время до вставки: цель ≤ 0,5 с на 5–15 с речи; измеряется на M5 владельца |
| Q3 | Лёгкость | Приложение в строке меню целый день | в простое ≈ 0 % процессора; память модели возвращается системе по бездействию |
| Q4 | Установка | Чужой Mac | dmg → «Всё равно открыть» → микрофон → модель скачана и проверена → работает офлайн |
| Q5 | Вес | — | установка по умолчанию ≤ 0,7 ГБ; всё необязательное — отдельной загрузкой |
| Q6 | Отзывчивость интерфейса | Любое действие | отражается сразу; движение прерываемо; выход быстрее входа |

Офлайн — принцип: сеть нужна один раз, чтобы скачать модель. Облачного пути нет.

## Состав

```
App (оболочка)            UI (SwiftUI, HUD)           Data (GRDB)
  AppState — только         читает состояние            история, лекции,
  связка и публикация       через узкие протоколы       очередь импорта
        │
DictationCoordinator ── владеет сессией: снимок приложения, окна, отмена
        │
SpeechPipeline  (локальный SPM-пакет, запрет импорта AppKit и GRDB)
  1. SpeechGate     VAD: есть ли речь, где её края
  2. SpeechEngine   реестр движков: Parakeet / Whisper / системный Apple
  3. TextSteps      цепочка шагов: подсказка → RUPunct → абзацы по паузам → словарь
  4. TextGuard      чистая функция: слова, длина, язык; при провале — откат на шаг назад
  → Draft { text, rawText, steps[], engineID, language, segments }
        │
Insertion (TextInserter)    Audio (AudioCaptureService)    Models (ModelStore)
```

Один конвейер на три входа — диктовка, импорт, лекция; у каждого свои окна и
подсказка языка, шаги общие.

## Границы

- `SpeechPipeline` не знает про AppKit, GRDB, сеть и файловую систему моделей.
  Нарушение — ошибка сборки, не правило в документе.
- Движок объявляет: id, языки, длину окна, выдаёт ли знаки, какие файлы нужны.
  Выбор движка по языку — чистая функция (как `LectureEngine.default`).
- `ModelStore` хранит модели по id: каталог, загрузка архивом, SHA-256 из
  вшитого в приложение списка, выгрузка по бездействию и по давлению памяти.
- Настройки сессии — неизменяемый снимок на старте записи.

## Что сохраняется без переписывания (проходит ревизию)

`TextInserter` и сценарий вставки, `DictationStateMachine`, `AudioCaptureService`,
лекции и `LiveTranscribing`, `Data/`, спецификация и тесты.

## Языки и движки (ожидаемо, окончательно — по бейкоффу блока M3)

| Язык | Движок | Запасной |
|---|---|---|
| ru, en | Parakeet TDT v3 (FluidAudio, CC-BY-4.0, ≈480 МБ) | Whisper turbo/полный + VAD + подсказка |
| zh | системный Apple `SpeechTranscriber` (macOS 26+) | Whisper turbo, опциональная загрузка |
| лекция вживую | системный, как сейчас | Whisper окнами |

Минимум системы — macOS 15; всё новее — за `#available` с запасным путём.

## Проверки архитектуры

- Пакет `SpeechPipeline` собирается без AppKit и GRDB (сборка падает при импорте).
- Конвейер проходит контрактный набор на поддельном движке без модели.
- Любой текстовый шаг: вывод не отличается от входа по набору значимых слов
  сверх допуска, иначе откат (тест в обе стороны).
- Просмотр записи в истории не пишет в базу (тест на счётчик записей).

## Не проверено (пробы идут первыми шагами плана)

- Знаки Parakeet v3 на русском: карточка NVIDIA говорит «да», замер FluidAudio — «нет».
- Поведение Parakeet на тишине и на смеси русского с английскими терминами.
- Системная модель Apple на китайском — только на синтезированной речи.
- Сохранение разрешений при самоподписанном сертификате на двух сборках подряд.
- Нужна ли LLM-правка: решается замером после подсказки и RUPunct (блок M4).
- Задержка «клавиша → плашка»: не измерена, подозрение — синхронный запуск микрофона.
