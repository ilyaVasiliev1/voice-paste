# Внешние зависимости

У каждой — договор: что мы от неё ждём и что ломается, когда она подводит.
Ни backend, ни сервера базы, ни очереди, ни ключей внешних служб у продукта нет.

---

## DEP-swift — Swift, Xcode и SDK macOS

Тулчейн сборки нативного приложения. Версия языка — 6.0, минимальная система —
`INV-002`.

Ломается: собрать приложение нечем.

- links: INV-002, L-016

## DEP-swiftui — SwiftUI и AppKit

Системные фреймворки интерфейса: menu bar, настройки, окно с разделением, панель
HUD.

Ломается: постоянные поверхности приходится рисовать самим, что запрещено `L-015`.

- links: L-015

## DEP-avfoundation — AVFoundation

Захват микрофона и чтение системно поддерживаемых медиафайлов, включая
пересемплирование под вход модели.

Ломается: диктовка и импорт остаются без источника звука.

- links: L-004

## DEP-opus — Системное декодирование OGG/Opus

Декодирование контейнера OGG с кодеком Opus выполняется системными средствами
CoreAudio и AVFoundation. Сторонние библиотеки для этого НЕ добавляются.

Подтверждено измерением на реальном голосовом сообщении Telegram: файл открылся
как 48 кГц моно, преобразование дало 16 кГц моно — ровно входной формат модели.
Доступно с macOS 12, минимальная система продукта выше.

Ломается: голосовые сообщения Telegram перестают приниматься, `EC-010` не
выполняется.

- links: EC-010, L-009

## DEP-grdb — GRDB поверх SQLite

Локальная история, словарь, миграции схемы и полнотекстовый поиск. Лицензия MIT,
подключается пакетным менеджером с закреплённой версией. База устройство НЕ
покидает.

Ломается: история и словарь остаются без хранилища.

- links: L-008

## DEP-whisperkit — WhisperKit

Локальное распознавание речи через Core ML. Лицензия MIT, подключается пакетным
менеджером с закреплённой версией. Ни платного уровня, ни облачного интерфейса
продукт НЕ использует.

Ждём от неё: открытие модели строго из локального пути с выключенной загрузкой,
чтобы отсутствующий токенизатор не запрашивался по сети.

Ломается: распознавание невозможно, продукт теряет главную функцию.

- links: L-010

## DEP-accessibility — Универсальный доступ и ApplicationServices

Регистрация глобального сочетания и доставка текста в активное приложение.
Требует разрешения системы.

Ломается: текст доставляется только через буфер обмена — `EC-002`.

- links: EC-002, L-007

## DEP-spellchecker — Системная проверка орфографии

Локальная проверка написания и определение языка словаря. Только как безопасный
слой поверх вывода модели.

Ломается: шаг проверки пропускается, текст не блокируется — `EC-011`.

- links: EC-011, L-006
