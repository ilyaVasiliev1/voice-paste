# Edge cases — VoicePaste

| ID | Условие | Ожидаемое поведение |
|---|---|---|
| EC-001 | Нет разрешения микрофона | Не начинать сессию; меню направляет в System Settings. |
| EC-002 | Нет Accessibility-разрешения | Можно распознать и скопировать; прямую вставку не обещать. |
| EC-003 | Пользователь жмёт hotkey во время обработки | Не создавать вторую сессию, сохранить текущую обработку. |
| EC-004 | Микрофон отключился во время записи | Остановить захват, сохранить только валидный буфер либо сообщить ошибку. |
| EC-005 | Пустая/очень короткая запись | Не вставлять пустой текст и не создавать пустую историю. |
| EC-006 | Целевое приложение закрылось/сменило фокус | Скопировать текст и честно показать `Текст скопирован`. |
| EC-007 | Мало диска для модели | Не начинать загрузку; показать требуемое и доступное место. |
| EC-008 | Модель повреждена или ОС очистила кэш | Пометить модель неготовой, предложить повторно загрузить/подготовить; не падать. |
| EC-009 | Неподдерживаемый/повреждённый файл | Не добавлять пустой элемент истории; показать имя и причину. |
| EC-010 | Telegram OGG/Opus | Локально декодировать и расшифровать; при повреждённом файле показать точную диагностируемую ошибку. Поддержка формата обязательна для релиза v1. |
| EC-011 | Русский spellchecker отсутствует | Не блокировать результат и не выполнять догадки по орфографии. |
| EC-012 | Текст содержит URL, код, номер или аббревиатуру | Не применять к ним догадочный автокоррект. |
| EC-013 | Многочасовой файл | Обработать потоково/с ограничением памяти, показывать прогресс; отмена освобождает ресурсы. |
| EC-014 | Выход приложения во время записи/обработки | Запросить подтверждение при активной записи; без незаметной потери готового текста. |
| EC-015 | Закрыто главное окно во время очереди | Не останавливать импорт: menu bar и worker продолжают работу, а при повторном открытии видны реальные state/progress очереди. |
| EC-016 | Явный выход во время очереди | Запросить подтверждение отмены активной и ожидающих задач; после подтверждения отменить worker и удалить временные каталоги jobs. |
| EC-017 | Неожиданное завершение процесса во время очереди | Не сохранять частичный текст; при следующем запуске вернуть незавершённые jobs в FIFO-очередь и начать их сначала из собственного временного source. |
| EC-018 | Мало места или ошибка чтения во время staging | Не создавать job в `queued`; показать короткую причину, закрыть security scope и удалить неполный временный каталог. |
| EC-019 | Видео без читаемой аудиодорожки | Не запускать Whisper; показать «В видео нет поддерживаемой аудиодорожки», в истории ничего не создавать. |
