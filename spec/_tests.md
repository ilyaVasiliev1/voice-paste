# Приёмочные тесты — VoicePaste

Это тесты приёмки для утверждения до реализации. Автоматизация допустима там, где не требует реального глобального хоткея, микрофона или системного диалога; остальные проходят на чистом Apple Silicon Mac с macOS 14+.

## Матрица способов доказательства

`passed` означает не «существует тест», а что выполнен подходящий способ проверки. QA фиксирует его в
отчёте для каждого запуска; reviewer не закрывает обязательный `живой smoke` одним unit-тестом.

| Группа AT | Базовый proof mode | Что дополнительно доказывается |
|---|---|---|
| AT-001…004, AT-092 | `живой smoke` + `user-confirmed` только для системного prompt | Установленный signed `.app`, повторная проверка TCC после возврата из Settings и после rebuild; модель реально загружается/переоткрывается. AT-092 — реальный лист согласия микрофона и появление приложения в списке «Микрофон»; детерминируемую логику «`false`+`notDetermined` ≠ отказ» покрыть `auto`/`integration`. |
| AT-005…011, AT-036, AT-043…046, AT-049, AT-051…054, AT-067, AT-073, AT-078…079, AT-083 | `живой smoke` | Реальный hotkey, микрофон, non-activating HUD, Finder/drop и motion. Для AT-037/046/051/054/083 — запись экрана 60 fps. |
| AT-012…020, AT-029…035, AT-039…042, AT-069…070, AT-072, AT-077, AT-080…082, AT-085 | `auto` или `integration` | Детерминированная нормализация, SQLite/FTS, pagination, миграции, статистика, словарь, очередь и политика допуска вставки; fixture не заменяет системный smoke. |
| AT-021…028, AT-059…066, AT-071, AT-074…076 | `integration` + `живой smoke` | Реальные fixtures форматов и файловых отказов, один активный worker, установленное приложение и lifecycle при закрытом окне. AT-024 всегда требует реальные Telegram OGG/Opus samples. |
| AT-006, AT-008, AT-055…058, AT-084 | `живой smoke` | Матрица TextEdit/Notes, Office, code editor/Terminal, browser contenteditable, messenger, desktop AI-chat и не-редактируемая цель; уникальная фраза появляется не более одного раза либо остаётся в clipboard согласно утверждённому контракту вставки. |
| AT-048, AT-050, AT-068, AT-087 | `живой smoke` | Финальные menu bar/HUD/Finder-сценарии в установленном приложении; AT-087 — открытие Настроек/О программе в menu-bar-only режиме. |
| AT-099…103 | `auto` + `integration` + `живой smoke` | Полностью offline cold start, ограниченная память длинного импорта, отсутствие main-thread hangs, согласованное сохранение очереди и профессиональная подпись/notarization. |
| AT-088, AT-089, AT-090, AT-091 | `живой smoke` | Линейный гейтинг маршрута первого запуска на установленном `.app`: точки входа ведут в онбординг до готовности, Dock-присутствие в онбординге без тупика, хоткей не перехватывается до готовности, «Настройки…» открывают Settings, а не историю. Детерминируемую часть (роутинг по состоянию, disabled-состояние, форс `.regular`) допускается покрыть `integration`. |

`blocked` допустим только как честный результат внешней среды с причиной и следующим действием. Он не
считается пройденным AT. Пользователь подтверждает лишь системный prompt или личный аккаунт, когда
агент не может сделать это сам; пользователь не заменяет QA-поиск багов.

| ID | Сценарий | Шаги | Ожидаемый результат |
|---|---|---|---|
| AT-001 | Первый запуск | Запустить без разрешений и модели. | Видны объяснения шагов; запись недоступна; приложение не падает. |

| AT-003 | Accessibility | Не выдавать Universal Access. До выдачи доступна расшифровка с честным копированием. До первой попытки нет второй конкурирующей команды «Открыть настройки системы»; после попытки она доступна как ручной fallback. | AT-014 | Неуверенная орфография | Подать слово с несколькими возможными заменами, URL и аббревиатуру. | Они не заменяются молча. |

## Обязательные quality gates до передачи пользователю

1. Unit-тесты: state machine диктовки, normalizer, словарь, история, модельный таймер.
2. Интеграционные тесты с моками: transcriber, audio input, pasteboard/accessibility, импорт.
3. QA-отчёт по матрице proof mode для AT-001…AT-084; AT-024 обязателен и не может быть помечен `passed` без реальных Telegram OGG/Opus sample.
4. Установленный signed `.app`: TCC smoke, реальный hotkey/Finder/media и внешняя матрица вставки; user-confirmed допускается только для OS prompt/личного аккаунта.
5. Xcode build с warnings-as-errors и VoiceOver smoke test для menu bar, Settings, History.
