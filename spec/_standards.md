# Standards проекта — macOS-профиль

> Полный профессиональный профиль, адаптированный для локального нативного приложения.

## Платформа, ростер и proof-gate

| Поле | Значение |
|---|---|
| Платформа | `macOS 14+ / Apple Silicon` |
| Реализация | Swift 6 + SwiftUI + AppKit; роль `macos` |
| QA-профиль | `_method/method/platform-profiles/macos.md` |
| Reviewer-профиль | `_method/method/platform-profiles/macos.md` |
| Обязательное доказательство | Автотесты + установленный signed `.app` + системный smoke TCC + реальные медиа + матрица вставки + visual/motion smoke HUD |

QA в отчёте помечает каждый обязательный AT как `auto`, `integration`, `живой smoke`, `user-confirmed`
или `blocked`. Зелёный `xcodebuild test` не закрывает разрешения macOS, внешние приложения или плавность.
Reviewer сверяет этот отчёт с profile и не считает задачу готовой при нераскрытом обязательном `blocked`.

| Пункт | Применяем? | Как/цель |
|---|---|---|
| Производительность | да | В простое CPU близок к нулю; тяжёлая транскрибация вне главного потока. |
| Надёжность | да | Явные состояния ошибок, безопасная отмена записи, восстановление после отказа разрешений. |
| Приватность | да | Распознавание локально; аудио не сохраняется по умолчанию. |
| Доступность | да | VoiceOver, клавиатурная навигация, Dynamic Type, системная контрастность. |
| Наблюдаемость | да | Локальные структурные логи без текста диктовок и без аудио. |
| Supply chain | да | Swift Package Manager с зафиксированными версиями и проверкой лицензий. |
| Аналитика | нет | Нет телеметрии в v1. |
| Авторизация | нет | Нет аккаунтов и сетевых пользователей. |
| Серверный SLA / healthcheck | не применимо | Серверов в v1 нет. |
