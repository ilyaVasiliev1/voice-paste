# Не входит в v1

- iOS, iPadOS, Windows, Linux и Intel Mac.
- Облачная обработка, синхронизация, совместная работа, аккаунты, подписки и аналитика.
- LLM-переписывание, изменение тона, составление писем, суммаризация и «исправление смысла» текста.
- Хранение исходного аудио/видео как архива внутри VoicePaste.
- Диаризация, таймкоды, главы, субтитры, параллельная обработка несколькими моделями и приоритизация очереди. В первом этапе есть только последовательная локальная FIFO-очередь, результат которой — чистый текст.
- Finder Quick Action / macOS Service «Транскрибировать в VoicePaste». Это следующий отдельный этап после приёмки стабильного импорта и очереди.
- Загрузка медиа по URL (YouTube, Instagram, TikTok и другие сервисы), авторизация в этих сервисах и обход их ограничений. Это отдельный этап после локальных файлов.
- Отдельное окно дашборда, тяжёлая аналитическая навигация и настраиваемые отчёты: в v1 есть только краткая локальная статистика в detail-области главного окна.
- Автоматическая загрузка медиа прямо из Telegram или интеграция с его аккаунтом; пользователь импортирует уже сохранённый локальный файл.
- Публикация в Mac App Store, notarization, автообновления и публичный GitHub-релиз. Это отдельный будущий контур.
