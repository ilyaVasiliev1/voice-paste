# Инварианты — VoicePaste

| ID | Инвариант |
|---|---|
| INV-001 | Цель v1 — macOS 14+ только на Apple Silicon; Intel не поддерживается. |
| INV-002 | Приложение нативное: Swift 6, SwiftUI + AppKit. Electron, webview и CSS-интерфейс не допускаются. |
| INV-003 | Диктовка, расшифровка, проверка орфографии, история и словарь работают локально. Учётных записей, аналитики, сервера и облачной транскрипции нет. |
| INV-004 | Единственная модель v1 — открытая WhisperKit-модель `large-v3-v20240930_626MB`. Модель и tokenizer **не входят в `.app`**. На единственном сетевом шаге онбординга пользователь выбирает GitHub Release, зеркало Hugging Face или официальный Hugging Face; после проверки оба артефакта устанавливаются в `~/Library/Application Support/VoicePaste/Models/` и повторно не загружаются. |
| INV-005 | Режим диктовки по умолчанию: одно нажатие hotkey запускает запись, следующее останавливает. Режим удержания — настройка. |
| INV-006 | HUD всегда расположен внизу по центру активного экрана, не у курсора и не захватывает фокус. |
| INV-007 | Перед обработкой текст получает пунктуацию от модели; автокоррекция применяется только к безопасным, однозначным случаям и личному словарю. Локальный LLM-редактор не используется. |
| INV-008 | При невозможности прямой вставки текст копируется в clipboard; пользователю показывается именно результат копирования. |
| INV-009 | Аудиозаписи и исходные импортированные файлы не сохраняются после задачи. История и словарь хранятся только в локальной SQLite-базе с миграциями и полнотекстовым индексом; настройки — в локальном UserDefaults. |
| INV-010 | UI v1 — русский, все строки локализуемы. Постоянные поверхности используют системные macOS-компоненты; custom UI ограничен HUD. |
| INV-011 | В бездействии не идёт захват аудио и не выполняется инференс. Модель выгружается через 10 минут по умолчанию, если пользователь не выбрал иначе. |
| INV-012 | Git в каталоге проекта не инициализируется в рамках текущей работы. |
| INV-013 | Импорт локальных медиа работает через одну локальную FIFO-очередь: одновременно выполняется не более одного декодирования/инференса WhisperKit; главное окно и HUD не выполняют тяжёлую работу на MainActor. |
| INV-014 | Временный source импортированной задачи живёт только в `Caches/VoicePaste/ImportQueue/<job-id>/` до её терминального статуса. Готовая история никогда не хранит путь, security bookmark или копию исходного медиа. |
| INV-016 | Глобальный хоткей и Escape во время записи регистрируются через системный `RegisterEventHotKey`; процесс **не устанавливает `CGEventTap` и не находится в тракте обычной клавиатуры/мыши**. До `ready` сочетание не зарегистрировано. Тяжёлая работа (копирование, аудиоконверсия, инференс WhisperKit, обход модели) выполняется вне MainActor. Ни занятый UI, ни остановленный debugger/test host не могут заморозить системный ввод. |
| INV-017 | Сеть разрешена только внутри явной первоначальной/повторной установки модели, пока онбординг показывает её прогресс. После успешной локальной проверки `ready` ни холодный старт, ни прогрев/инференс, ни диктовка, импорт, история или настройки не создают исходящих соединений. Аудио, текст, логи и метаданные никогда не покидают Mac. Отсутствующая/повреждённая модель возвращает приложение в явный model-step; скрытой фоновой загрузки нет. |
| INV-018 | Импорт не материализует весь PCM длинного файла в памяти. Декодирование, ресемплинг и инференс идут последовательными ограниченными окнами; в памяти одновременно находится только текущее окно и малый overlap. Один активный worker сохраняется для всей очереди. |
| INV-019 | MainActor содержит только состояние и UI. Дискретная синхронная работа на главном потоке укладывается в 100 ms, непрерывные UI-обновления — в кадровый бюджет; в Hangs/Time Profiler нет зависания ≥250 ms, вызванного VoicePaste, во время старта, импорта, транскрибации, сохранения или остановки hotkey. |
| INV-020 | Публичный `.app` собирается Release-конфигурацией с Hardened Runtime, entitlement микрофона, стабильным bundle ID и Developer ID/notarization. Если Developer ID ещё не предоставлен, локальная self-signed сборка маркируется development и не выдаётся за профессиональный релиз; ограничение Gatekeeper/TCC показывается честно. |
| INV-015 | Пока `readiness != ready`, приложение находится в едином не-готовом контуре: activation policy принудительно `.regular` (приложение видно в Dock) независимо от сохранённого `showInDock`; единственное доступное окно — онбординг; все точки входа (пункты меню «Открыть VoicePaste»/«Статистика», reopen по Dock, launch) ведут в онбординг; команда записи и импорт **disabled** (не «ошибка по нажатию»); глобальный хоткей не перехватывается системно (сочетание доходит до активного приложения). Только после `ready` применяется настройка `showInDock` и открывается полный функционал. Тупиковых состояний, из которых нельзя вернуться в онбординг, не существует. |
