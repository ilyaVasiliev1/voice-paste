# План — переделка ядра и оболочки (с 2026-10-14)

Утверждён владельцем 14.10.2026. Устройство — `ARCHITECTURE.md`; исследование — `research/`.
Сделанный шаг сворачивается в одну строку со ссылкой на коммит.

## Решения владельца (14.10.2026)

- Только офлайн; облачного пути нет. Китайские лекции остаются.
- Без Developer ID и нотаризации: путь «Всё равно открыть» остаётся; README исправляется.
- Минимум системы — macOS 15; новое — за `#available`.
- Accessibility необязателен: без него текст остаётся в буфере с подсказкой ⌘V.
- Прежнее содержимое буфера возвращается после успешной вставки; «вставить последнее» — отдельная клавиша.
- Переключатель «сохранять звук для оценки»: выключен, локально, удаляется кнопкой.
- Плашка: добавляются выход 120 мс и прогрев; вид не меняется.
- Атрибуция CC-BY — в «О программе» и README.
- Вес установки по умолчанию ≤ 0,7 ГБ; локальная LLM — не в первой версии, решается замером.
- Сохраняемое проходит ревизию, а не просто остаётся.

## Две дорожки

Две длинные сессии, каждая в своей ветке и рабочей копии; слияние после обеих.

| | Механика | Дизайн |
|---|---|---|
| Ветка | `core/pipeline` | `ui/polish` |
| Папки | `Core/`, `App/`, `Data/`, `scripts/`, `spec/`, `Packages/` | `UI/`, `Core/HUD/` |
| Не трогает | `UI/` — только заявкой | `AppState`, всё остальное в `Core/` |

**Контракт между дорожками.** Механика держит публичную поверхность `AppState` неизменной до слияния.
Интерфейсу нужно новое поле или действие — заявка строкой в «Заявки интерфейса» ниже, механика
добавляет аддитивно. Остановки только две: после бейкоффа (M3) — выбор движка владельцем по числам;
перед слиянием.

## Механика

### M1. Основа и дешёвые победы
Статус: ждёт
Контекст: `docs/status.md` (блокеры), `research/…-hallucination-and-speed.md`, `AppState.swift:737-846`.
Части: (1) тесты на тракт диктовки — протоколы `AudioSource`, `TextDelivering`, поддельные часы; (2) причина «Thank you» —
журнал определённого языка, закрепление языка по умолчанию; (3) VAD перед моделью и фильтр по аудио вместо списка фраз;
(4) SHA-256 модели при загрузке; (5) переключатель звука для оценки; (6) наблюдатель смены микрофона;
(7) README: убрать правый клик.
Навыки: `tdd-workflow`, `systematic-debugging`, `swift-concurrency:swift-concurrency`, `swift-testing-expert:swift-testing-expert`, `done-check`
Готово когда: красные тесты по каждому пункту стали зелёными; 12 известных записей с «Thank you» воспроизведены тестом или причина названа; тишина даёт пустой результат.

### M2. Конвейер и координатор
Статус: ждёт; зависит от M1
Части: пакет `Packages/SpeechPipeline` (шаги, страж, `Draft`); `DictationCoordinator` вынесен из `AppState`;
три входа (диктовка, импорт, лекция) на одном конвейере.
Навыки: `architecture`, `tdd-workflow`, `swift-concurrency:swift-concurrency`
Роли: `code-reviewer` — раз по окончании
Готово когда: пакет собирается без AppKit и GRDB; прежние 275 тестов зелёные; `AppState` меньше 600 строк.

### M3. Реестр движков и бейкофф
Статус: ждёт; зависит от M2
Части: описание движка, `ModelStore` по id; адаптеры Parakeet v3 / Ultra, Whisper (turbo, `large-v3_947MB`, `_turbo_632MB`),
системный Apple; набор записей (30–50 фраз вслух + тишина + шум + китайские лекции); стенд замера; режим тени.
Критерий выбора по порядку: (1) тишина — ноль текста; (2) русский не хуже нынешнего turbo, допуск назовёт владелец по числам;
(3) скорость на клипах 5–15 с; (4) знаки; (5) вес в бюджете.
Навыки: `search-first`, `benchmark`, `tdd-workflow`
Готово когда: таблица чисел на M5 владельца; **остановка — выбор за владельцем**.

### M4. Текстовые шаги
Статус: ждёт; зависит от M3
Части: подсказка-образец; RUPunct (ONNX, проверка лицензии пакета); абзацы по паузам; режимы «сообщение» и «промпт»
без LLM; страж; замер LLM на M5 — включать ли.
Готово когда: F1 запятой и точки на размеченных текстах не ниже порога, названного по замеру; страж ловит «ответ вместо правки» в обе стороны.

### M5. Установка и разрешения
Статус: ждёт; зависит от M1
Части: постоянный самоподписанный сертификат (проверка, что разрешения переживают две сборки); Accessibility необязателен;
автозагрузка модели с первой секунды; прогрев после смены сборки macOS в онбординге; выгрузка по бездействию.
Готово когда: чистая установка на втором Mac или чистой учётной записи проходит без объяснений; разрешения не сбрасываются.

### M6. Функции для работы с агентами
Статус: ждёт; зависит от M2
Части: «удержание или защёлка» в автомате; CLI и URL scheme (`toggle`, `transcribe`, `last`); возврат буфера и «вставить последнее»;
постхук; поиск по истории и лекциям для агентов.
Готово когда: блоки спеки и тесты; CLI-контракт описан одним JSON.

### M7. Ревизия сохранённого
Статус: идёт параллельно M2–M6
Части: `code-reviewer` по всем линзам над вставкой, автоматом, захватом, лекциями, хранилищем; 518 мёртвых ссылок на старую нумерацию;
42 блока спеки без доказательства; импорт: задачи с неизвестным состоянием не отбрасываются молча.
Готово когда: находки закрыты или названы принятыми владельцем.
