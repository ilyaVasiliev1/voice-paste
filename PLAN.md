# План — переделка ядра и оболочки (с 2026-10-14)

Утверждён владельцем 14.10.2026. Устройство — `ARCHITECTURE.md`; исследование — `research/`.
Сделанный шаг сворачивается в одну строку со ссылкой на коммит.

## Решения владельца (14.10.2026)

- Только офлайн; облачного пути нет. Китайские лекции остаются.
- Без Developer ID и нотаризации: путь «Всё равно открыть» остаётся; README исправляется.
- Минимум системы — macOS 15; новое — за `#available`.
- Accessibility необязателен: без него текст остаётся в буфере с подсказкой ⌘V.
- Прежнее содержимое буфера возвращается после успешной вставки; «вставить последнее» — отдельная клавиша.
- Переключатель «сохранять звук для оценки»: выключен, локально, удаляется кнопкой.
- Плашка: добавляются выход 120 мс и прогрев; вид не меняется.
- Атрибуция CC-BY — в «О программе» и README.
- Вес установки по умолчанию ≤ 0,7 ГБ; локальная LLM — не в первой версии, решается замером.
- Сохраняемое проходит ревизию, а не просто остаётся.

## Две дорожки

Две длинные сессии, каждая в своей ветке и рабочей копии; слияние после обеих.

| | Механика | Дизайн |
|---|---|---|
| Ветка | `core/pipeline` | `ui/polish` |
| Папки | `Core/`, `App/`, `Data/`, `scripts/`, `spec/`, `Packages/` | `UI/`, `Core/HUD/` |
| Не трогает | `UI/` — только заявкой | `AppState`, всё остальное в `Core/` |

**Контракт между дорожками.** Механика держит публичную поверхность `AppState` неизменной до слияния.
Интерфейсу нужно новое поле или действие — заявка строкой в «Заявки интерфейса» ниже, механика
добавляет аддитивно. Остановки только две: после бейкоффа (M3) — выбор движка владельцем по числам;
перед слиянием.

## Заявки интерфейса к механике

1. **Сборка на Xcode 27.** `AppState.beginFileImport`: `[weak self]` внутри `DispatchQueue.main.async` — ошибка
   `ImplicitStrongCapture`, сборка останавливается целиком. Поправлено одной строкой в `ui/polish` (b285b37) по слову
   владельца 14.10; при слиянии хунк тот же. Ещё два места, мешающих собираться, поправлены в `ui/polish` по слову владельца: `SystemLiveTranscriber`
   (незанятая задача с `try`; механика правит настоящей правкой — при слиянии берётся её версия) и
   `HistoryStoreTests.swift:516` (`Row` не `Sendable`; правка только теста, конфликта не ждём).
2. ~~Прогрев окна истории~~ — **снята замером 14.10**: первая страница 0,2–0,7 мс, открытие модели 2,1 мс
   (`research/2026-10-14-d1-measurements.md`). Прогревом остаток ожидания не сократить: он в построении сцены окна.
3. **Веер перерисовок (D1, п. 13, остаток).** `AppState` пересылает `objectWillChange` от лекции, импорта и модели,
   а `lectureElapsedSeconds` — `@Published` на самом `AppState`: любой вид с `@EnvironmentObject appState` пересчитывается
   два раза в секунду во время лекции. Дизайн сузил подписку у истории и статистики; чтобы убрать источник, тикер
   лекции должен жить в `LectureRecorder`, а не в `AppState`. Решает механика.
4. **Плашка до `start()` микрофона (D2, п. 12 аудита).** `AppState.beginRecording` показывает плашку после
   `audioCapture.start()`, который на главном акторе строит `AVAudioEngine`. Нужно: показать `.recording(0, 0)` до
   `start()`, при отказе морфить в `.error` (плашка это умеет). Сначала замер «клавиша → `orderFront`» через
   `os_signpost` в `handleHotkeyDown`; без него величина неизвестна. Решает механика.
