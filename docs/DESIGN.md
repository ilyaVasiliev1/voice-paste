# VoicePaste — интерфейс

Собственный интерфейс на SwiftUI по референсу владельца: плоская боковая панель, список записей и просторный документ. Системные NavigationSplitView, List и toolbar не задают композицию главного окна. Telegram — ориентир для ясности действий и выделения, без копирования исходников или ресурсов.

## Композиция

Боковая панель — 220 pt, список — 260–300 pt, документ — от 450 pt. Заголовки колонок высотой 56 pt разделены тонкими линиями. Минимум окна — 930×460 pt; стандартный размер — 1120×680 pt. Документ не растягивает строки шире 680 pt. Импорт и статистика ограничены 860 pt. Действия располагаются в собственной шапке документа; поиск — в списке истории.

Палитра WorkspacePalette определяет нейтральные поверхности для обеих тем. Акцент выделяет главное действие. Выбранная строка и наведение различаются заливкой. Кнопки WorkspaceActionStyle и строки WorkspaceRowStyle имеют единое оформление. Недоступные действия приглушаются. Системный шрифт сохраняет хорошее отображение китайского текста.

## Настройка

Онбординг — 720×480 pt: этапы слева, объяснение и действие справа. Микрофон, доступ для автоматической вставки и локальная модель проверяются по настоящему состоянию системы. Прокрутка не уводит кнопки перехода за край окна.

Настройки имеют собственную боковую навигацию по пяти разделам. Системные поля, переключатели, меню выбора, редактор текста, Finder и окна разрешений используются там, где важны привычное поведение и доступность.

## Состояния

Пустая история, загрузка, ошибка чтения и отсутствие выбранной записи различаются. Лекция с неполной расшифровкой показывает предупреждение в списке и причину в документе. Общие предупреждения находятся под документом и не смещают шапки колонок.

Проверка — изолированные снимки истории, лекций, импорта, статистики, настроек и онбординга в обеих темах, на минимальной и широкой компоновке. Пользовательская история и настоящий микрофон для демонстрации не используются.
