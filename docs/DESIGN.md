# VoicePaste — нативный интерфейс macOS

Используются NavigationSplitView, системные списки, панели инструментов, меню, поля и настройки SwiftUI/AppKit. Цвета, выделение, фокус клавиатуры и материалы следуют macOS. Отдельная библиотека рисованных контролов не используется.

## Главное окно

Разделы слева, список по центру, выбранная запись справа. Ширины и минимум окна определяются MainWindowLayout. Действия находятся в системной панели инструментов; поиск связан с историей. В настройках пять разделов постоянно доступны через системный сегментированный переключатель.

## Лекции

Заголовок, дата и длительность отделены от документа. У каждого абзаца своя отметка времени, текст можно выделить и скопировать. Для китайского и длинных записей используется более крупный текст с увеличенным межстрочным интервалом. Таймер записи виден постоянно; остановка выделена красным. Меню языка и движка компактные, с подсказками; главное действие не должно исчезать при минимальной ширине окна.

Неполная расшифровка показывает предупреждение и причину. Промежуточный текст отличается от окончательного; состояние ожидания не изображается фиктивными абзацами.

## Первый запуск и версия

Онбординг использует обычное окно macOS и системные кнопки. Микрофон, доступ для вставки и модель проверяются по фактическому состоянию системы. Версия, номер сборки и источник доступны в настройках; установленная копия одна.

## Проверка

Изолированные снимки всех разделов, настроек и первого запуска: обе темы, минимальная и широкая компоновка. Публичные скриншоты содержат только демонстрационные записи.
