# Проверки, выпуск и обновление

## Зависимости

Первая машина один раз получает закреплённые пакеты:

```bash
xcodebuild -resolvePackageDependencies -project VoicePaste.xcodeproj -scheme VoicePaste \
  -clonedSourcePackagesDirPath "$HOME/Library/Caches/VoicePaste/SourcePackages" \
  -onlyUsePackageVersionsFromResolvedFile
```

Последующие сборки используют этот кэш и отключают автоматическое разрешение версий.

## Проверки

```bash
python3 scripts/test-build-info.py
zsh scripts/test-safely.sh
```

Тестовый хост изолирован от истории, настроек и горячей клавиши установленного приложения. Снимки на демонстрационных данных:

```bash
zsh scripts/snapshots.sh .artifacts/screenshots
```

## Версия и происхождение

`MARKETING_VERSION` — версия продукта, `CURRENT_PROJECT_VERSION` — номер сборки в проекте Xcode. При выпуске номер увеличивается. `build-info.py` записывает SHA-256 исходников, ревизию git и дату сборки до подписи. Незакоммиченные изменения дают другой отпечаток даже при одинаковом HEAD.

Установленная копия показывает версию и отпечаток в настройках. Журнал установок находится в `~/Library/Application Support/VoicePaste/installations.json`; он не содержит пользовательских расшифровок.

## Одна локальная копия

Целевой путь всегда `/Applications/VoicePaste.app`. Собранные `.app` в кэшах — промежуточные артефакты; их не нужно запускать как отдельные версии. Тестовый хост снимается с регистрации Launch Services после прогона.

Для владельца, который обновляет приложение из исходников, создаётся отдельная локальная подпись:

```bash
zsh scripts/setup-build-keychain.sh
```

Пароль генерирует и хранит скрипт с правами 600. При обычном обновлении связка и сертификат не пересоздаются. Если существующая связка есть, а её пароль отсутствует, настройка останавливается. Нельзя подменять подпись или сбрасывать доступ автоматически.

Закройте VoicePaste и установите новую сборку:

```bash
zsh scripts/install-local.sh
zsh scripts/verify-local.sh
```

Установщик сначала собирает и подписывает временную копию. Только после проверки он заменяет приложение; при неудаче возвращает прежнюю копию. Модель, настройки и история не перемещаются. Отказ подписи останавливает обновление до замены. Откат к тегу или коммиту идёт через тот же установщик: `zsh scripts/rollback-local.sh v0.2.0`.

Локальная подпись владельца не используется для публичного DMG. При переходе между разными подписями macOS может потребовать переоформить разрешение; обычные обновления с одной локальной подписью её не меняют.

## Публичный выпуск

```bash
zsh scripts/build-release.sh
```

Скрипт собирает Release, записывает происхождение, проверяет отсутствие встроенной модели, подписывает и формирует DMG без Finder и системных диалогов. По умолчанию подпись ad-hoc, без нотаризации; это явно указано в README и выпуске.

Для Developer ID передаются `SIGN_IDENTITY`, при необходимости `SIGN_KEYCHAIN` и `NOTARY_PROFILE`. Значения ключей и пароли не входят в репозиторий. Для подписи и нотаризации нужен настроенный владельцем сертификат Apple.

Выпуск публикуется из проверенного коммита: тег версии, `VoicePaste.dmg`, SHA-256 и описание изменений. Исходники на GitHub и установленная сборка сверяются по метаданным, а не по имени файла.
